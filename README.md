## ☁️ Overview

**Cryptography_Money** is an educational project that bridges the gap between cryptographic theory and cryptocurrency applications. It provides hands-on implementations and experiments covering:

* **Cryptographic Algorithms** – Classical and modern encryption techniques
* **Blockchain Technology** – Fundamentals of distributed ledgers
* **Cryptocurrency Mechanics** – Mining, wallets, transactions, and consensus protocols
* **Security Practices** – Hash functions, digital signatures, and key management
* **Practical Applications** – Real-world use cases of cryptography in financial systems

This project serves as both a **learning resource** for understanding cryptographic principles and a **practical toolkit** for cryptocurrency experimentation.

## ⚙️ Requirements

* Python 3.8+
* Jupyter Notebook or JupyterLab (for interactive notebooks)
* Recommended libraries:
  * `cryptography` – Modern cryptographic recipes
  * `hashlib` – Secure hash and message digest algorithms
  * `ecdsa` – Elliptic Curve Digital Signature Algorithm
  * `pycryptodome` – Cryptographic library
  * `web3.py` – Ethereum blockchain interaction (if applicable)
  * `numpy`, `matplotlib` – For data analysis and visualization

Install dependencies:

```sh
pip install -r requirements.txt
```

## 🚀 Usage

Clone the repository:

```sh
git clone https://github.com/WTFitsmemyself/Cryptography_Money.git
cd Cryptography_Money
```

Start exploring the project:

```sh
# For Jupyter notebooks
jupyter notebook

# For Python scripts
python examples/basic_encryption.py
```

Explore different modules:

* **algorithms/** – Implement and test various encryption/decryption methods
* **blockchain/** – Build and simulate simple blockchain networks
* **cryptocurrency/** – Experiment with wallet generation, transaction signing, and mining algorithms
