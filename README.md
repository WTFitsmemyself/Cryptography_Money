## ☁️ Overview
**Cryptography_Money** is a Jupyter Notebook project designed for exploring cryptography techniques and their applications in financial systems.
It provides workflows for:
* Data encryption and decryption
* Cryptographic algorithms and secure hashing
* Blockchain basics and cryptocurrency simulations
* Experimentation with secure financial transactions
This project is intended both as a **learning resource** and as a **sandbox for cryptography experiments**.
---
## 📂 Project Structure
```
Cryptography_Money/
│
├── Crypto/ # Notebooks and scripts related to cryptographic tasks
├── Financial.ipynb # Notebook for financial data handling & exploration
├── .idea/ # IDE settings (PyCharm, etc.)
├── .ipynb_checkpoints/ # Jupyter notebook checkpoints
├── database.sqlite # SQLite database (metadata / storage)
└── README.md
```

## ⚙️ Requirements
* Python 3.x
* Jupyter Notebook or JupyterLab
* Recommended libraries:
  * cryptography, pycryptodome
  * pandas, numpy
  * matplotlib, seaborn
  * hashlib (for hashing tasks)
Install dependencies (if available):
```sh
pip install -r requirements.txt
```
---
## 🚀 Usage
Clone the repository:
```sh
git clone https://github.com/WTFitsmemyself/Cryptography_Money.git
cd Cryptography_Money
```
Start Jupyter Notebook or Lab:
```sh
jupyter notebook
# or
jupyter lab
```
Open and run the notebooks:
* Begin with `Financial.ipynb` for data insights
* Explore `Crypto/` notebooks for encryption techniques and financial cryptography experiments
